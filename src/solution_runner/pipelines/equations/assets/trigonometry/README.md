# Статические SVG для табличных тригонометрических значений

Это очищенные производные эталонного SVG из Lessons Helper. Они создаются скриптом автора один раз и затем прикрепляются раннером как готовые файлы; во время обработки задач SVG не генерируются. Точки пересечения подписаны точными углами, а подписи используют Liberation Sans с запасным DejaVu Sans.
