# Группа 27766 — blocked

Статус проверен read-only `2026-09-06`. В группе существует ровно одна
задача: источник `27766`, internal id
`3a40040c-5451-45e2-b254-d03e27a70583`. Все входные стадии готовы, но
Helpers находится в `pending`; p2–p5 также pending, p6 not_required.

Единственная задача одновременно является обязательным родителем. В группе
нет non-parent repair child, поэтому невозможно выполнить обязательный
acceptance-proof из `docs/runner-authoring-contract.md`: продемонстрировать
child-specific вычисление на отличающихся значениях и доказать, что раннер не
копирует решение родителя статически. Соответственно, для этой группы нельзя
честно зарегистрировать профиль или запускать `--apply` только ради Helpers.

Прочитано ровно разрешённое содержание родителя. Он просит острый угол между
биссектрисами острых углов прямоугольного треугольника; существующие ответ
`45` и решение нуждаются в отдельной авторской проверке, но не создают
разрешённого ребёнка. Нужна явная отмена требования non-parent acceptance
child для single-task groups либо добавление репрезентативного ребёнка в
каталог. До этого причина является group-level контрактным blocker, а не
основанием для MCP-записи.
