## Общие компоненты

Из раннера группы 185 переиспользуются `QuadraticChoice`, точные `Fraction`,
модель `Interval`, форматирование промежутков, SVG-шаблон оси и renderer
метода интервалов, общий diagram gateway, frozen manifest и readback.
Новые неравенства разбираются ограниченным арифметическим AST без выполнения
произвольных выражений. Поддержаны перенос правой части, смена знака при
отрицательном старшем коэффициенте, произведения двух линейных множителей,
целые и рациональные корни. Иррациональные корни и другая грамматика блокируются.

В решении сначала идут исходное неравенство и преобразования до произведения,
затем отдельной строкой рисунок: знаки внутри трёх дуг, синяя штриховка
под осью только у подходящих промежутков, прозрачный фон. После рисунка —
отдельная строка `x\in` с множеством решений и пустая строка. Дробные подписи
в SVG рисуются числителем, чертой и знаменателем; сырой TeX в SVG не попадает.
Старые рисунки решения удаляются только по их ключам, без изменения картинок
условия. Новый рисунок имеет один ключ `generated_quadratic_solution` и позицию 0.

## Проверенные данные

`quadratic_interval_choices_evidence.json` содержит точную контрольную сумму
условия, исходную формулу и четыре независимо прочитанных множества решений.
Для изображений сохранены UUID и SHA256. Визуально проверены 63 задачи с
картинками, включая две составные растровые картинки. Текстовые интервалы
разбираются точно, с сохранением строгих/нестрогих концов и порядка вариантов.
Номер ответа определяется совпадением независимо решённого неравенства
с одним из проверенных множеств; сохранённый ответ не участвует в выборе.

Заблокированы две задачи группы 338499:

- **338678**: второй вариант повреждён до `(-5\cdot 5)`; по имеющемуся контенту
  нельзя подтвердить полный исходный промежуток. Варианты не придумываются.
- **480243**: вместо четырёх рисунков сохранены текстовые описания изображений.
  Без самих рисунков нельзя надёжно проверить порядок и границы.

Все остальные 97 задач независимо проверены через SymPy. Материализация
их планов реальными серверными `materialize_problem_transformations` и
`validate_normalized_content` не дала ошибок; HTML и порядок ассетов совпали
с ожидаемыми. Тесты моделируют служебные атрибуты сервера, удаление старых
рисунков и повторное применение без новых записей или загрузок.

Запуск одной зарегистрированной группы:

```bash
.venv/bin/solution-runner \
  --group 338497 \
  --confirm-catalog fd733f80-43d2-4b4a-b903-2423796cbee5 \
  --max-workers 3 --batch-size 10
```

`--apply` добавляется после dry-run. Применение по всем 14 группам в этой
сессии явно разрешено пользователем.

## Результат применения 29.10.2026

Контент **97 задач применён** с успешным authoritative readback; две
перечисленные задачи заблокированы до исправления источника. Исправлены
четыре сохранённых ответа: 338731 (`000 → 3`), 338735 (`1 → 2`),
403152 (`0 → 1`), 403431 (`2 → 3`).

Этап Helpers для 97 задач отклонён сервером:
`409: source content write fence is busy`. Повторный последовательный
запуск группы 311310 подтвердил отсутствие изменений контента
(`already_complete`), но Helpers снова встретили ту же блокировку.
Снятие серверной блокировки не входит в работу раннера; её нельзя обходить.
После освобождения fence можно повторить `--apply`: контент и сохранённые
SVG переиспользуются, а этап Helpers завершится штатным stage-control gateway.

После снятия блокировки 29.10.2026 выполнен отдельный последовательный
запуск `--helpers-from-existing-solution --apply`: **Helpers ready у всех
97 обработанных задач**. 96 состояний обновлены, одно уже было готово после
контрольного запуска. Задачи 338678 и 480243 исключены из выборки. Сравнение
Normalized до и после запуска для всех 99 задач подтвердило отсутствие
изменений контента.

## Ручные исправления двух исключений

По отдельному указанию пользователя обе задачи исправлены напрямую через
MCP, без запуска или расширения раннера:

- **338678** (`2f22cfaa-0f08-40a5-93fa-4b9602fd99a9`): во втором варианте
  `(-5\cdot 5)` заменено на `(-5;5)`. Точка с запятой подтверждается
  сохранённым Parsed alt-текстом; скобки и числа сохранены. Добавлено
  решение методом интервалов. Ответ **1** сохранён.
- **480243** (`8ef56d6a-33f6-4a53-8bc0-4c783c13beca`): при первом ручном
  исправлении машинные описания отсутствующих изображений ошибочно удалены
  вместе с вариантами ответа. Задача временно стала открытой с ответом
  `(-∞;-6)∪(6;+∞)`. Это изменило формат задания и впоследствии исправлено
  по запросу пользователя, как описано ниже.

Обе иллюстрации переиспользованы из существующих SourceAsset с точным
совпадением SHA256: `e8ae8d1a-4206-42df-9d49-c5b1bc6e6cca` и
`9cac43c3-6dab-4426-b10b-cb89a238d375`. Новых загрузок нет. Преобразования
условий и решений проверены реальным серверным материализатором перед
записью и повторным чтением после записи; ответы не менялись. Эти задачи
остаются ручными исключениями в evidence раннера, чтобы он не перезаписывал
ручные исправления.

При попытке завершить Helpers у этих двух ручных исправлений сервер вновь
вернул `409: source content write fence is busy` — и для общей операции,
и для отдельных задач с заново прочитанными токенами. Повторное чтение
подтвердило прежний статус Helpers `failed`; контент сохранён и корректен.
Helpers первых 97 задач ранее завершены успешно. Эти две записи требуют
повторного штатного обновления Helpers после освобождения серверного fence.

После повторного запроса пользователя серверный fence освободился: Helpers
обоих ручных исправлений обновлены штатным MCP stage-control batch и
подтверждены отдельным повторным чтением. Итог для 338678 и 480243:
aggregate `ready`, P2–P5 `ready` (revision 2), P6 `not_required` (revision 1).
