# Гиперболы 508951 и 508961

Каталог `41bc4d03-40cd-4407-8dea-df76e3f47ea8`, категория 12,
тема `4309cd49-7738-4b5a-b0d8-3892b940e5db`.

| Группа | UUID группы | Родитель | Правило |
| --- | --- | --- | --- |
| 508951 | `84eff141-c86b-4919-bd7f-384a62eb21cf` | 508951 / `de6bf611-902c-4952-b81c-e25323375982` | `hyperbola-shift-value` |
| 508961 | `0c1b13d3-a625-4f9d-95f4-cef5cb087a19` | 508961 / `371e1a7e-a8c1-4657-8b16-dc617e02ec7b` | `hyperbola-shift-argument` |

Основная форма обеих групп — `f(x)=k/x+a`. В первой спрашивается значение
функции, во второй — аргумент по значению. Раннер считывает оси, шаг сетки,
горизонтальную асимптоту и отмеченную точку из текущего SVG; считает точными
рациональными числами. Ответ не используется для восстановления коэффициентов.

Решение содержит два способа:

1. Без заголовка способа: подстановка двух красных точек в формулу,
   цепочка равносильных систем через `\iff`, вычисление параметров и ответ.
   Формулы выводятся в режиме display с дробями `\frac`; лишние скобки
   у положительных чисел отсутствуют, вычисление заканчивается десятичным ответом.
   Вторая точка выбирается на видимой части исходного графика.
2. «Альтернативное решение»: величина и направление сдвига асимптоты,
   знак `k` по четвертям относительно асимптот и обратная пропорциональность
   `x` и `y-a`. Красный горизонтальный отрезок
   на уровне одной клетки выше асимптоты позволяет найти `k` по отступу.
   Если этот уровень вне рисунка, используется уровень ниже асимптоты.

Из условия удаляются мягкие переносы. Исходные изображения, их ссылки и
идентификаторы сохраняются. В каждом рисунке решения исходный SVG сохранён
побайтово: перед закрывающим тегом добавлена только группа красных отметок.
Сетка, кривая, асимптоты, подписи, размеры и viewBox не перерисовываются.
Посторонние иллюстрации сохраняются; прежние ошибочно перерисованные графики
исключаются из решения.

`function_graphs/diagrams.py` добавляет отметки кодом. Исходники и варианты
хранятся в `assets/hyperbolas/`, варианты опубликованы как SourceAsset и
закреплены в `source-assets.json`. На каждый уникальный исходный SVG
приходится вариант с точками и вариант с отрезком. Раннер проверяет SHA-256
исходника и соответствие параметров, общий runtime прикрепляет варианты.
Повторный запуск не добавляет дубликатов. Для PNG используются исходные
изображения без красных отметок.

Для не-SVG сохраняется исходное изображение и добавляется предупреждение в
манифест/результат. Числа восстанавливаются из согласованной подстановки исходного
решения. Такой формат сам по себе не блокирует задачу. Если числовых данных нет
либо они противоречат формуле, задача остаётся blocked без записи; группа
продолжает обрабатывать остальные задачи. Повторный запуск поддерживается и для
уже собранного решения.

Неоднозначные оси/сетка/маркер, неизвестная форма условия, нулевая абсцисса,
недостижимая ордината и нетерминирующий десятичный ответ блокируют только задачу.

Особые задачи 508987 и 508988 в группе 508961 используют `f(x)=k/(x+a)`.
Их исходные PNG визуально проверены; коэффициенты и отмеченные точки закреплены
по SHA-256 байтов (не по ответам). Первый способ подставляет две симметричные
точки, второй отсчитывает абсциссу от вертикальной асимптоты: `X=x+a`, `Xy=k`.
Исходные PNG не заменяются. Неизвестные байты требуют отдельной проверки.

У 508987 вертикальная асимптота `x=1`, отмеченная точка `(2;-3)`, поэтому
`f(x)=-3/(x-1)`. При `f(x)=0,15` ответ `-19`; сохранённый ответ `14` расходится
с графиком. Раннер предлагает исправление с предупреждением. У 508988
асимптота `x=-2`, точка `(3;-1)`, `f(x)=-5/(x+2)` и ответ `38`.

```bash
.venv/bin/solution-runner --group 508951 \
  --confirm-catalog 41bc4d03-40cd-4407-8dea-df76e3f47ea8 \
  --only-source-problem-id 508951 --only-source-problem-id 508952 \
  --max-workers 2 --batch-size 2 --apply

.venv/bin/solution-runner --group 508961 \
  --confirm-catalog 41bc4d03-40cd-4407-8dea-df76e3f47ea8 \
  --only-source-problem-id 508961 --only-source-problem-id 508962 \
  --max-workers 2 --batch-size 2 --apply
```

В ручном режиме команды с `--apply` запускает пользователь согласно контракту
разработки. Удаление `--apply` даёт проверку без записи и без Initialize.


## Горизонтальный сдвиг: 508971 и 508983

Группы `b7df39c8-06a2-46ca-b69b-a7ad420cc81e` (12 задач) и
`bec09ca3-a236-47aa-9fcd-776884b9a05a` (10 задач) используют правила
`hyperbola-shift-horizontal-value` и `hyperbola-shift-horizontal-argument`.
Они явно исправляют ошибочную формулу `f(x)=k/x+a` на `f(x)=k/(x+a)`
в условии, сохраняя тег изображения. Уже правильная формула сохраняется.
Режим исправления не применяется к группам вертикального сдвига.

Коэффициенты считываются из вертикальной асимптоты `x=-a` и синей точки
исходного SVG: `k=(x+a)y`. Несколько пунктирных отрезков на одной прямой
считаются одной асимптотой. Поддерживаются десятичные и смешанные аргументы.
Два способа оформлены как в предыдущих группах: сначала график, затем
цепочка систем через `\iff`; альтернативный способ кратко объясняет
горизонтальный сдвиг, знак `k` по четвертям и отступ от вертикальной асимптоты.

В задаче 635859 SVG содержит внешний JPEG. Исходник сохраняется без
перерисовки и используется в обоих способах без красных отметок; предупреждение
записывается в манифест. Координатные элементы SVG не имеют преобразований,
поэтому числовые данные считываются по прежнему правилу.

```bash
.venv/bin/solution-runner --group 508971 \
  --confirm-catalog 41bc4d03-40cd-4407-8dea-df76e3f47ea8 \
  --max-workers 3 --batch-size 12 --apply
.venv/bin/solution-runner --group 508983 \
  --confirm-catalog 41bc4d03-40cd-4407-8dea-df76e3f47ea8 \
  --max-workers 3 --batch-size 10 --apply
```


По отдельному запросу исходные PNG 508987 и 508988 заменены соответствующими
SVG. В 635859 удалён единственный внешний JPEG-элемент: его правая граница
`11.1565` находится левее начала viewBox `20`, он целиком вне видимого рисунка.
Остальные байты SVG сохранены. Чистый SVG переиспользуется для 508988 и 635859.
Во всех трёх задачах теперь есть два SVG решения с красными отметками;
актуальные запуски не выдают предупреждений о формате или внешних ссылках.
Старые PNG/исходный SVG остаются в фикстурах для проверки резервного пути.

## Дробно-линейная функция: 508993 и 509001

Группы `508993` (`b4a0f3c7-c5de-4c56-a003-7c236d2be077`) и `509001` (`25605c37-1c45-4790-9713-6711d0b2090a`) зарегистрированы правилом
`hyperbola-shift-fractional-coefficient`. Раннер исправляет ошибочную формулу
`k/x+ax+b` на `(kx+a)/(x+b)` для вопроса о коэффициенте `k`, `a` или `b`.
Оси, обе асимптоты и отмеченные точки считываются из исходного SVG. Числа
вычисляются точно, согласованность всех отмеченных точек проверяется.

Первый способ подставляет три видимые точки в систему для `k`, `a`, `b`;
После подстановки отдельно показаны устранение знаменателей, раскрытие скобок и перенос слагаемых. Вычитание второго и третьего уравнений из первого исключает `a`; затем последовательно находятся `b`, `k` и `a`. Параметры находятся из системы без чтения асимптоты в тексте решения. Второй подробно выделяет целую часть
через `+kb-kb`, группировку `k(x+b)+(a-kb)`, разделение дроби и сокращение.
Перед преобразованиями дана короткая цель: привести формулу к каноническому
виду гиперболы. После них объясняются —
вертикальный сдвиг `k`, горизонтальный сдвиг `b` и роль `a-kb`.
Горизонтальная асимптота `y=k` даёт ответ.

SVG и варианты с отметками обеих групп закреплены в `assets/fractional-hyperbolas/`.
Для исходного вида `(ax+b)/(x+c)` раннер сохраняет обозначения, включая
`A=b-ac`, `B=c`, `C=a`.
Полный запуск: 508993 — все 12 задач применены; 509001 — все 8 задач применены.
Для 564963 без маркеров отдельно проверены три пересечения кривой с сеткой:
`(3;-1)`, `(1;-7)`, `(5;-3)`. Расстояния до исходных кривых меньше половины
толщины их штриха; аудит привязан к SHA-256 исходного SVG. Отметки добавляются
только в SVG решения, условие сохраняется.
Исходные рисунки условий сохранены, повторное планирование изменений не даёт.
При замене обозначений сохраняются команды LaTeX и названия окружений
`cases`; все формулы обеих групп дополнительно проверяются рендерером KaTeX.

```bash
.venv/bin/solution-runner --group 508993 \
  --confirm-catalog 41bc4d03-40cd-4407-8dea-df76e3f47ea8 \
  --max-workers 3 --batch-size 12 --apply
```


В конце альтернативного способа явно вводится канонический вид
`f(x)=A/(x+B)+C`, где `A=a-kb`, `B=b`, `C=k`. Роль каждого коэффициента
объясняется и его значение находится по графику. Для 508993:
`A=5`, `B=4`, `C=1`, `f(x)=5/(x+4)+1`. Если требуется исходный `a`,
после пустой строки раннер показывает `A=a-kb → a=A+kb`,
соответствия `k=C`, `b=B` и подстановку с промежуточным произведением; вопрос о другом коэффициенте не подменяется
поиском `k`. В группе 509001 восстанавливается свободный член числителя.

## Обратная пропорциональность: 660801

Группа `660801` (`67db17c6-c0a4-477d-8564-a9eeb199d4f1`) зарегистрирована
правилом `hyperbola-unshifted-value`. В функции `f(x)=k/x` одна неизвестная:
первый способ подставляет одну точку, второй читает знак ветвей и отступ от
оси ординат на высоте `y=1`. Оба способа заканчиваются вычислением значения
функции и десятичной дробью.

660801: `(1;1)`, `k=1`, `f(10)=0,1`; 685371: `(3;1)`, `k=3`, `f(30)=0,1`;
704625: `(5;1)`, `k=5`, `f(10)=0,5`. Исходный PNG последней задачи по запросу
заменён векторным SVG с той же системой координат, гиперболой и подписями.
Остальные SVG условий сохранены. В иллюстрациях решений добавляется только
красная точка или горизонтальный отрезок. Материалы закреплены в
`assets/unshifted-hyperbolas/`; для зарегистрированного PNG раннер также
поддерживает сохранение исходника с предупреждением без остановки группы.

```bash
.venv/bin/solution-runner --group 660801 \
  --confirm-catalog 41bc4d03-40cd-4407-8dea-df76e3f47ea8 \
  --max-workers 3 --batch-size 3 --apply
```
