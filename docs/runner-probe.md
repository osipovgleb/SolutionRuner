# Проверка одной задачи существующими раннерами

`solution-runner-probe` — read-only эвристика для поиска уже существующего
детерминированного правила, которое теоретически может подойти новой группе.

Пробник:

- принимает ровно одну задачу;
- отказывается работать, если у неё нет записанного ответа;
- один раз читает её Normalized transformation context;
- прогоняет условие через каждый уникальный зарегистрированный content-rule;
- считает кандидатом только правило, которое приняло условие и независимо
  вычислило тот же ответ;
- ничего не записывает и не выставляет Helpers ready.

Совпадение ответа не доказывает совместимость решения, ассетов или всей
грамматики группы. Порядок проверки кандидата описан в [контракте](runner-authoring-contract.md).

По видимому номеру задачи внутри явного каталога:

```bash
.venv/bin/solution-runner-probe \
  --source-problem-id SOURCE_TASK_NUMBER \
  --confirm-catalog CATALOG_SNAPSHOT_ID
```

По внутреннему UUID задачи:

```bash
.venv/bin/solution-runner-probe --problem-id PROBLEM_UUID
```

Дополнительные режимы:

- `--json` — машиночитаемый полный отчёт;
- `--show-rejections` — показать причины отказа строгих парсеров.

Геометрические профили, которым сначала требуется подготовленное изображение,
не выдаются за проверенные: отчёт показывает их отдельным счётчиком.
